# nativeapi_flutter

Flutter integration for [nativeapi](https://pub.dev/packages/nativeapi): unified access to native system APIs — windows, tray icons, menus, displays, keyboard, dialogs, storage and more.

🚧 **Work in Progress**: for now this package re-exports [`nativeapi`](https://pub.dev/packages/nativeapi) unchanged. Flutter-specific APIs will move here.

## Installation

```bash
flutter pub add nativeapi_flutter
```

```dart
import 'package:nativeapi_flutter/nativeapi_flutter.dart';
```

Everything that `package:nativeapi/nativeapi.dart` exports is available through this import.
